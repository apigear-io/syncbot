Activation Logs

This page shows historical logs from endpoint activations. Each log captures the full output from post-activation commands.

Features
  • View - Open the log content in a modal with search/filter
  • Download - Download the complete log file
  • Delete - Remove individual or multiple logs
  • Batch Delete - Select multiple logs and delete them at once
Log Files

Logs are named using the pattern: {endpoint}_{timestamp}.log

Example: my-endpoint_20250115-143052.log

Log Rotation

Logs are automatically managed:

  • Maximum 10 MB per log file (rotates if exceeded)
  • Keeps up to 5 rotated backups
  • Old logs cleaned up after 30 days
  • Rotated files are compressed (.log.gz)
Log Location

Logs are stored at:
{{.EndpointsPath}}/.syncbot-logs/

Live View

Click "Live View" to go to the Active page and see real-time command output as it happens.
