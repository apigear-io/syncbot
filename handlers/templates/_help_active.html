Active Endpoint

This page shows the currently active endpoint and the output from the post-activation command.

Process Status
  • Idle - No process has run yet
  • Running - Post-activation command is executing
  • Stopped - Process exited normally
  • Killed - Process was terminated by user or new activation
  • Failed - Process failed to start
Controls
  • Kill - Stop the running process (sends SIGTERM, then SIGKILL)
  • Clear - Clear the output buffer
  • Auto-scroll - Automatically scroll to new output
How It Works

When you activate an endpoint, the post-activation command (configured in Settings) runs in the background. The output streams here in real-time via Server-Sent Events (SSE).

If you activate a new endpoint while a command is still running, the previous command is automatically killed.

Future Log Sources

This page is designed to support multiple log sources. Future versions may include:

  • System logs (syslog, journalctl)
  • Application-specific log files
  • Custom log streams
