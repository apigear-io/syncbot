Backups

This page lists all backup archives created from endpoints.

Creating Backups
  1. Go to the Endpoints page
  2. Click the Edit button on an endpoint
  3. Configure Backup Patterns (e.g., *.log, config/*)
  4. Save the endpoint
  5. Click the Backup button (archive icon) on that endpoint
  6. Preview the files, then click Create Backup
Backup Patterns

Patterns use glob syntax:

  • * - matches any files in current directory
  • ** - matches directories recursively
  • ? - matches single character
Examples
  • *.log - all .log files in root
  • logs/**/*.log - all .log files in logs/ recursively
  • config/*.json - all .json files in config/
Storage

Backups are stored in the backups/ folder relative to the SyncBot executable as .tgz archives.
