User Commands

Define custom shell commands that can be executed on the device. Commands are useful for common operations like restarting services, clearing caches, or running diagnostics.

Creating a Command

Click Add Command and fill in:

  • Command ID: Unique identifier (lowercase, hyphens allowed)
  • Name: Display name for the command
  • Description: Optional explanation of what it does
  • Shell Command: The actual command to run
Running Commands

Click the Run button next to any command. The output (stdout and stderr) will be displayed in a modal dialog.

Note: Commands run with the same permissions as the SyncBot process. Be careful with commands that modify system state.

Template Variables

Commands support Go template syntax for dynamic values:

{{"{{"}}.HomeDir{{"}}"}}User's home directory
{{"{{"}}.EndpointsPath{{"}}"}}Path to endpoints directory
{{"{{"}}.ActiveSymlink{{"}}"}}Path to active symlink
{{"{{"}}.ActiveName{{"}}"}}Name of active endpoint
{{"{{"}}.DeviceName{{"}}"}}Device name
{{"{{"}}.DeviceIP{{"}}"}}Device IP address
Tip: Click "Show/Hide" on the Template Variables card to see current values.

Example Commands

Restart a service
sudo systemctl restart myapp
List active endpoint contents
ls -la {{"{{"}}.ActiveSymlink{{"}}"}}
Show disk usage
df -h {{"{{"}}.EndpointsPath{{"}}"}}
Check active endpoint version
cat {{"{{"}}.ActiveSymlink{{"}}"}}/version.txt
Tail application logs
tail -n 50 /var/log/myapp.log
