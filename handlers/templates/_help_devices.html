Device Registry

The Devices view shows all SyncBot instances in your network. This helps users quickly navigate between different test devices.

Adding Devices

Click Add Device to add devices individually or import multiple devices at once.

Device Fields
  • Name: Device display name (required)
  • URL: Full URL to SyncBot instance (required)
  • Description: Brief description (optional)
  • Location: Physical location (optional)

CSV Import

To quickly add multiple devices, use the CSV Import tab. Paste your device list in CSV format:

name,url,description,location
device-01,http://192.168.1.100:8081,Primary,Room 101
device-02,http://192.168.1.101:8081,Secondary,Room 102
Options
  • Replace all: Removes existing devices and imports only the CSV data
  • Append: Adds CSV devices to existing list (default)
Tip: The header row is optional and will be auto-detected and skipped.
