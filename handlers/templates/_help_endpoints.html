Managing Endpoints

Creating an Endpoint

Click Create Endpoint and enter:

  • Endpoint Name: A unique identifier (e.g., "feature-xyz", "john-test")
  • Owner: Your name, so others know who to contact
Deleting an Endpoint

Click Delete on your endpoint. You must enter your owner name to confirm. Note: You cannot delete the currently active endpoint.

Naming Rules

Endpoint names must be alphanumeric with hyphens only (e.g., "my-release-v2").

Syncing Your Software

Getting the rsync Command

Click the rsync button on your endpoint to get the exact command.

Command Format
rsync -avzc --delete /local/path/ user@device:/path/to/endpoint/
Flags Explained
  • -a Archive mode (preserves permissions, timestamps)
  • -v Verbose output
  • -z Compress during transfer
  • -c Use checksum to verify file integrity
  • --delete Remove files on target that don't exist locally
Platform-Specific Paths

macOS / Linux:

/Users/name/releases/v1.0/

Windows (Git Bash):

/c/Users/name/releases/v1.0/

Windows (WSL):

/mnt/c/Users/name/releases/v1.0/

Activating Endpoints

What Activation Does
  1. Updates the symlink to point to your endpoint
  2. Runs the configured post-activation command
Before Activating

Check who currently has the active endpoint and coordinate with them if needed.

Note: Activating an endpoint may interrupt testing for the current user. Always coordinate with your team!
