Application Logs

View and search SyncBot application logs. Logs are stored in memory and cleared on restart.

Features
  • Search: Filter logs by message content
  • Level Filter: Show only specific log levels
  • Auto-refresh: Automatically update logs every 5 seconds
  • Clear: Remove all log entries
Log Entry Fields
  • Timestamp: When the event occurred
  • Level: Severity (error, warn, info, debug)
  • Component: Source module (http, activation, etc.)
  • Message: Event description

Log Levels

Level Description
error Critical errors requiring attention
warn Warning conditions that may need review
info Informational messages about normal operations
debug Detailed debugging information
Tip: Filter by "error" level to quickly find problems.

Filtering Logs

Text Search

Type in the search box to filter logs by message content. Search is case-insensitive.

Example searches:

  • endpoint - Show endpoint-related events
  • activation - Show activation events
  • failed - Show failure messages
Level Filter

Use the dropdown to show only logs of a specific severity level.

Combining Filters

Text search and level filter can be combined. For example, select "Errors" and search for "activation" to see only activation-related errors.
