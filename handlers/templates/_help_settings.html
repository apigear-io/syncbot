Settings Overview

Configure your SyncBot instance settings here. Changes are saved to the configuration file.

Device Information
  • Device Name: A friendly name for this device
  • Location: Physical location (e.g., "Room 101")
  • Description: Brief description of this device's purpose
Network Settings
  • Device IP/Hostname: IP or hostname used for rsync commands
  • SSH Username: Username for SSH connections
  • Port: Web server port (requires restart to change)

Path Configuration

Endpoints Path

Directory where endpoint folders are created:

/home/user/syncbot/endpoints

Each endpoint creates a subfolder here (e.g., /home/user/syncbot/endpoints/my-release).

Active Symlink Path

Symlink that points to the currently active endpoint:

/home/user/syncbot/active

Your application should reference this symlink to always use the active release.

Post-Activation Command

Shell command executed after activating an endpoint. Common examples:

# Restart a service
sudo systemctl restart myapp

# Run a custom script
/home/user/scripts/deploy.sh

# Multiple commands
sudo systemctl stop myapp && sleep 2 && sudo systemctl start myapp

Running as a Service

Create systemd Unit File
[Unit]
Description=SyncBot - Endpoint Sync Manager
After=network.target

[Service]
Type=simple
User=syncbot
WorkingDirectory=/opt/syncbot
ExecStart=/opt/syncbot/syncbot
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
Installation Steps
# Save unit file
sudo nano /etc/systemd/system/syncbot.service

# Reload systemd
sudo systemctl daemon-reload

# Enable and start
sudo systemctl enable syncbot
sudo systemctl start syncbot

# Check status
sudo systemctl status syncbot
View Logs
journalctl -u syncbot -f
