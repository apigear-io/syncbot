Settings Sync

The sync feature allows you to copy configuration from a "master" SyncBot device to this device. This is useful when managing multiple instances across different machines.

How It Works
  • Pull-based: This device fetches settings from the master
  • Selective: You choose exactly what to sync
  • Non-destructive: Only selected items are changed
What Can Be Synced
  • Device information (name, description, location)
  • Path settings (endpoints, symlinks)
  • Network settings (IP, SSH username)
  • User-defined commands
  • Device registry

Sync Workflow

  1. Connect: Enter the master device URL and connect
  2. Settings: Review and select device settings to sync
  3. Commands: Select commands to add or replace
  4. Devices: Select device registry entries to sync
  5. Review: Confirm your selections and apply
Smart Defaults

The wizard pre-selects items that differ between devices, except for device-specific settings like paths and IP addresses which you typically want to keep unique per device.

Master URL Memory

The master URL is saved in your browser so you don't need to re-enter it next time.
