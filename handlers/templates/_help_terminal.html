Terminal

Access an interactive shell on this device through your browser.

PIN Access

Terminal access is protected by a 4-digit PIN stored in your browser.

  • Setup: First-time users create a PIN
  • Remember PIN: Optionally store for auto-login
  • Reset: Click "Reset PIN" to clear and set a new one
Session Timeout

Sessions automatically expire after 15 minutes of inactivity. You'll receive a warning 2 minutes before timeout.

Configuration

The shell can be configured in config.yaml:

terminal:
  shell: /bin/bash
Keyboard Shortcuts
  • Ctrl+C - Interrupt current command
  • Ctrl+D - End of input / logout
  • Ctrl+L - Clear screen
  • Tab - Auto-complete
